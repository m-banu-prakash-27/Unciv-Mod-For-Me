# v3.2 – Gifting and Promotions

- Retains v3.1 mod systems.
- Adds explicit Magalanadu first, second and Justice promotions to all 53 custom units (existing MAG-41 / Indian Missile Cruiser promotions preserved).
- Adds 91 G&K compatible standard promotion rules using the built-in `relevant` filter for newly-trained units.
- Ensures all 53 custom units have foreign-border entry (necessary but not sufficient for stock major-civ gifting).
- Clarifies that true gifting without Open Borders requires a patched Unciv 4.22.16 executable. Full source patch is distributed separately.
- Does not claim automatic transfer of the recipient's resources or Gold per turn. v3.1 export payout remains a mod-generated Gold bonus.
