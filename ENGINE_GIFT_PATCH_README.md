# Engine patch availability

To donate Magalanadu units to major civilizations without Open Borders, install a custom Unciv 4.22.16 build compiled from the separate `Magalanadu_v3.2_Engine_Patch_Kit.zip`. The engine patch file is not part of this JSON mod.

Stock Unciv requires friendly territory for major-Civ gifts and cannot be bypassed with a JSON `unique`. If using the ordinary app, gift from friendly recipient territory only. Detailed instructions are in README.md.
